Running a session

  1. Write the brief first. One clear sentence naming the objective. A vague brief does not "open up" creativity; it scatters it.
  2. Draw a card. Use all categories for a random jolt, or narrow to the categories that fit where you are in the process.
  3. Set the timer and apply the card literally. Do exactly what the card says, against your brief, until the timer runs out. Five to ten minutes per card works well.
  4. Capture everything. One idea per line in the Ideas box. Quantity over quality; no editing while generating.
  5. Draw again, or combine. Use Combo mode to collide two different kinds of thinking on the same brief.
  6. Converge last. Only after generating, switch to critique: pick the strongest few, then use a Limitation or Mental Model card to test them.

The six suits

Draw modes

  • 1 card: a single prompt to work on. Best for solo, timed sprints.
  • 3 cards: a spread read as Warm up, Shift, Push. Work them in order, one timer each.
  • Combo: two cards from two different suits. Apply both at once (for example, Imagine You're the Devil + Five Whys).

Using it with a group

  • Draw from In Groups first to choose the session format (Brain Writing, Step Ladder, Anonypost).
  • Then draw content cards from the other suits and put one on screen for everyone.
  • Generate individually before sharing, so the loudest voice doesn't set the direction.
  • Evaluate ideas anonymously, ideally by someone outside the group.
